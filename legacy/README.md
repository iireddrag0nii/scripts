# Legacy Installation Scripts

These files represent the original HBTECHSOLUTIONS
infrastructure installation scripts.

They are preserved for historical reference and to
document the evolution of this project.

## Original Components

- Docker installation
- Portainer deployment
- WireGuard / wg-easy deployment
- Pi-hole installation
- Password generation helper

## Important

These scripts are unmaintained and have not been
validated against current software releases.

Do not execute them on production systems.

The original README is preserved as README-original.md.

Modern, supported deployment configurations will be
developed under Infrastructure Deployment Toolkit v2.0.
